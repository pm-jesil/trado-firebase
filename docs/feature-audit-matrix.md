## Key Verifications & Architectural Invariants

1. **Multi-Tenant Boundary**: Every operational query and mutation enforces `organizationId`. Cross-tenant data leakage is prevented by Firestore Rules and `resolveRequestContext`.
2. **Branch Context Scope**: Physical inventory (`stockBalances`), branch assignments (`membershipBranches`), and document numbering are scoped to the active branch.
3. **Double-Entry Party Ledgers**: Bills increment customer receivables; payments and returns decrement them. Purchases increment vendor payables; payments decrement them. Both are audited by `reconcilePartyLedgers`.
4. **Weighted-Average Costing**: Inventory intake calculates WAC with 4-decimal precision, preventing rounding drift and accurately computing COGS on sales.
