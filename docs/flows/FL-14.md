# FL-14: Cashier Shift Handover & Receiver Confirmation

> **Domain:** Finance, Stock & Account Integrity (Prompt 77)  
> **Personas:** `cashier_shift1`, `cashier_shift2`  
> **Key Invariants:** `INV-1`, `INV-3`, `INV-4`  
> **Callables:** `accountTransfersCreate`, `accountTransfersConfirm`  

---

## 1. Overview
Morning cashier transfers physical cash drawer to evening cashier. Receiver must confirm receipt before transfer completes.

## 2. Executable Steps & Request Payloads

### Step 1: Create handover transfer
- **Callable:** `accountTransfersCreate`
- **Request Payload:**
```json
{
  "sourceAccountId": "acc_drawer_1",
  "destinationAccountId": "acc_drawer_2",
  "amount": 150000,
  "transferType": "shift_handover"
}
```

### Step 2: Incoming cashier confirms handover
- **Callable:** `accountTransfersConfirm`
- **Request Payload:**
```json
{
  "transferId": "trf_h1"
}
```


## 3. Invariant Assertions & Expected State
- **INV-1:** Must hold before and after each transaction in this flow.
- **INV-3:** Must hold before and after each transaction in this flow.
- **INV-4:** Must hold before and after each transaction in this flow.
- Balance updates must be atomic and synchronized across running balance fields.
