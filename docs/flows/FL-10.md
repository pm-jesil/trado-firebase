# FL-10: Inter-Branch Stock Transfer (Dispatch -> Transit -> Receipt)

> **Domain:** Finance, Stock & Account Integrity (Prompt 77)  
> **Personas:** `warehouse_dispatcher`, `branch_receiver`  
> **Key Invariants:** `INV-11`, `INV-12`, `INV-13`  
> **Callables:** `stockTransfersCreate`, `stockTransfersSubmit`, `documentsDecide`, `stockTransfersDispatch`, `stockTransfersReceive`  

---

## 1. Overview
Transferring finished stock between warehouses. Source decrements physical and increments in_transit; destination increments on receipt.

## 2. Executable Steps & Request Payloads

### Step 1: Create transfer draft
- **Callable:** `stockTransfersCreate`
- **Request Payload:**
```json
{
  "sourceBranchId": "branch_w1",
  "destinationBranchId": "branch_s1",
  "items": [
    {
      "productId": "prod_1",
      "requestedQty": 50
    }
  ]
}
```

### Step 2: Submit and approve transfer
- **Callable:** `documentsDecide`
- **Request Payload:**
```json
{
  "documentType": "stock_transfer",
  "documentId": "trf_001",
  "decision": "approve"
}
```

### Step 3: Dispatch from warehouse
- **Callable:** `stockTransfersDispatch`
- **Request Payload:**
```json
{
  "transferId": "trf_001"
}
```

### Step 4: Receive at retail branch
- **Callable:** `stockTransfersReceive`
- **Request Payload:**
```json
{
  "transferId": "trf_001",
  "items": [
    {
      "productId": "prod_1",
      "receivedQty": 50
    }
  ]
}
```


## 3. Invariant Assertions & Expected State
- **INV-11:** Must hold before and after each transaction in this flow.
- **INV-12:** Must hold before and after each transaction in this flow.
- **INV-13:** Must hold before and after each transaction in this flow.
- Balance updates must be atomic and synchronized across running balance fields.
