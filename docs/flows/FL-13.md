# FL-13: Stock Transfer Cancel-After-Dispatch (In-Transit Reversal)

> **Domain:** Finance, Stock & Account Integrity (Prompt 77)  
> **Personas:** `dispatcher`, `branch_manager`  
> **Key Invariants:** `INV-11`, `INV-13`  
> **Callables:** `stockTransfersDispatch`, `stockTransfersCancel`  

---

## 1. Overview
Transfer vehicle recalled due to road closure. Dispatched items in transit are safely credited back to source warehouse.

## 2. Executable Steps & Request Payloads

### Step 1: Dispatch transfer
- **Callable:** `stockTransfersDispatch`
- **Request Payload:**
```json
{
  "transferId": "trf_003"
}
```

### Step 2: Cancel dispatched transfer
- **Callable:** `stockTransfersCancel`
- **Request Payload:**
```json
{
  "transferId": "trf_003",
  "reason": "Vehicle recall / aborted trip"
}
```


## 3. Invariant Assertions & Expected State
- **INV-11:** Must hold before and after each transaction in this flow.
- **INV-13:** Must hold before and after each transaction in this flow.
- Balance updates must be atomic and synchronized across running balance fields.
