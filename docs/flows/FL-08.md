# FL-08: Sales Return with Customer Store Credit

> **Domain:** Finance, Stock & Account Integrity (Prompt 77)  
> **Personas:** `cashier`, `branch_manager`  
> **Key Invariants:** `INV-1`, `INV-5`  
> **Callables:** `returnsCreate`, `accountEntriesList`  

---

## 1. Overview
Customer returns merchandise and elects store credit. No immediate cash leaves drawer; customer advanceBalance is incremented.

## 2. Executable Steps & Request Payloads

### Step 1: Create return with credit_note refund
- **Callable:** `returnsCreate`
- **Request Payload:**
```json
{
  "referenceBillId": "bill_001",
  "refundMethod": "credit_note",
  "items": [
    {
      "productId": "prod_1",
      "returnQty": 1
    }
  ]
}
```

### Step 2: Verify customer advance balance updated
- **Callable:** `accountEntriesList`
- **Request Payload:**
```json
{
  "sourceDocumentType": "return"
}
```


## 3. Invariant Assertions & Expected State
- **INV-1:** Must hold before and after each transaction in this flow.
- **INV-5:** Must hold before and after each transaction in this flow.
- Balance updates must be atomic and synchronized across running balance fields.
