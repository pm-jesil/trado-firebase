# FL-11: Inter-Branch Transfer Discrepancy & Damage Write-Off

> **Domain:** Finance, Stock & Account Integrity (Prompt 77)  
> **Personas:** `branch_receiver`, `operations_manager`  
> **Key Invariants:** `INV-11`, `INV-12`  
> **Callables:** `stockTransfersReceive`, `stockTransfersResolveDiscrepancy`  

---

## 1. Overview
Goods arrive damaged at destination. Damaged units are rejected, and an inventory write-off expense is charged to source branch.

## 2. Executable Steps & Request Payloads

### Step 1: Receive with shortage and rejection
- **Callable:** `stockTransfersReceive`
- **Request Payload:**
```json
{
  "transferId": "trf_002",
  "items": [
    {
      "productId": "prod_1",
      "receivedQty": 45,
      "rejectedQty": 5,
      "discrepancyReason": "transit_breakage"
    }
  ]
}
```

### Step 2: Resolve discrepancy as write_off
- **Callable:** `stockTransfersResolveDiscrepancy`
- **Request Payload:**
```json
{
  "transferId": "trf_002",
  "productId": "prod_1",
  "resolution": "write_off",
  "notes": "Breakage during highway transport"
}
```


## 3. Invariant Assertions & Expected State
- **INV-11:** Must hold before and after each transaction in this flow.
- **INV-12:** Must hold before and after each transaction in this flow.
- Balance updates must be atomic and synchronized across running balance fields.
