# FL-05: Vendor Credit Purchase & Subsequent Settlement

> **Domain:** Finance, Stock & Account Integrity (Prompt 77)  
> **Personas:** `purchaser`, `accountant`  
> **Key Invariants:** `INV-1`, `INV-3`, `INV-4`  
> **Callables:** `outflowsCreate`, `paymentsCreate`, `accountEntriesList`  

---

## 1. Overview
Purchasing raw materials on vendor credit terms. Vendor payable increases; settlement payment zeroes out the liability.

## 2. Executable Steps & Request Payloads

### Step 1: Create vendor credit purchase
- **Callable:** `outflowsCreate`
- **Request Payload:**
```json
{
  "kind": "purchase",
  "vendorId": "vend_1",
  "totalAmount": 200000,
  "paidAmount": 0
}
```

### Step 2: Issue vendor payout voucher
- **Callable:** `paymentsCreate`
- **Request Payload:**
```json
{
  "vendorId": "vend_1",
  "amount": 200000,
  "paymentMethod": "bank_transfer",
  "direction": "out"
}
```


## 3. Invariant Assertions & Expected State
- **INV-1:** Must hold before and after each transaction in this flow.
- **INV-3:** Must hold before and after each transaction in this flow.
- **INV-4:** Must hold before and after each transaction in this flow.
- Balance updates must be atomic and synchronized across running balance fields.
