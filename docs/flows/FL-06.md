# FL-06: Operational Expense Posting (Cash & Bank)

> **Domain:** Finance, Stock & Account Integrity (Prompt 77)  
> **Personas:** `branch_manager`, `finance_manager`  
> **Key Invariants:** `INV-1`, `INV-3`, `INV-4`  
> **Callables:** `outflowsCreate`, `accountEntriesList`  

---

## 1. Overview
Recording daily branch operating expenses (e.g. utilities, store cleaning, packaging supplies) against cash drawer.

## 2. Executable Steps & Request Payloads

### Step 1: Post expense outflow
- **Callable:** `outflowsCreate`
- **Request Payload:**
```json
{
  "kind": "expense",
  "totalAmount": 12000,
  "paidAmount": 12000,
  "paymentMethod": "cash",
  "notes": "Store cleaning supplies"
}
```

### Step 2: Verify expense recorded in cash drawer ledger
- **Callable:** `accountEntriesList`
- **Request Payload:**
```json
{
  "sourceDocumentType": "outflow"
}
```


## 3. Invariant Assertions & Expected State
- **INV-1:** Must hold before and after each transaction in this flow.
- **INV-3:** Must hold before and after each transaction in this flow.
- **INV-4:** Must hold before and after each transaction in this flow.
- Balance updates must be atomic and synchronized across running balance fields.
