# FL-07: Sales Return with Cash Refund

> **Domain:** Finance, Stock & Account Integrity (Prompt 77)  
> **Personas:** `cashier`, `branch_manager`  
> **Key Invariants:** `INV-1`, `INV-2`, `INV-3`, `INV-5`  
> **Callables:** `returnsCreate`, `documentsDecide`, `accountEntriesList`  

---

## 1. Overview
Customer returns defective item and receives cash refund. Stock is re-credited and cash drawer balance reduced.

## 2. Executable Steps & Request Payloads

### Step 1: Create sales return
- **Callable:** `returnsCreate`
- **Request Payload:**
```json
{
  "referenceBillId": "bill_001",
  "refundMethod": "cash",
  "items": [
    {
      "productId": "prod_1",
      "returnQty": 1
    }
  ]
}
```

### Step 2: Approve sales return
- **Callable:** `documentsDecide`
- **Request Payload:**
```json
{
  "documentType": "return",
  "documentId": "ret_001",
  "decision": "approve"
}
```


## 3. Invariant Assertions & Expected State
- **INV-1:** Must hold before and after each transaction in this flow.
- **INV-2:** Must hold before and after each transaction in this flow.
- **INV-3:** Must hold before and after each transaction in this flow.
- **INV-5:** Must hold before and after each transaction in this flow.
- Balance updates must be atomic and synchronized across running balance fields.
