# FL-12: Intra-Branch Location Move (Internal Stock Transfer)

> **Domain:** Finance, Stock & Account Integrity (Prompt 77)  
> **Personas:** `storekeeper`, `branch_manager`  
> **Key Invariants:** `INV-11`, `INV-12`  
> **Callables:** `stockTransfersCreate`, `stockTransfersDispatch`, `stockTransfersReceive`  

---

## 1. Overview
Moving items between different storage racks or rooms within the same branch. Marked internal: true with no in-transit ledger charge.

## 2. Executable Steps & Request Payloads

### Step 1: Create internal transfer
- **Callable:** `stockTransfersCreate`
- **Request Payload:**
```json
{
  "sourceBranchId": "branch_main",
  "destinationBranchId": "branch_main",
  "sourceLocationId": "rack_a",
  "destinationLocationId": "rack_b",
  "internal": true,
  "items": [
    {
      "productId": "prod_1",
      "requestedQty": 20
    }
  ]
}
```


## 3. Invariant Assertions & Expected State
- **INV-11:** Must hold before and after each transaction in this flow.
- **INV-12:** Must hold before and after each transaction in this flow.
- Balance updates must be atomic and synchronized across running balance fields.
