# FL-01: Cash Sale & Immediate Ledger Posting

> **Domain:** Finance, Stock & Account Integrity (Prompt 77)  
> **Personas:** `cashier`, `branch_manager`  
> **Key Invariants:** `INV-1`, `INV-2`, `INV-3`, `INV-4`  
> **Callables:** `billsCreate`, `billsFinalize`, `accountEntriesList`  

---

## 1. Overview
Retail walk-in customer makes a cash purchase. Bill is finalized, stock decremented, and cash drawer account entry posted immediately.

## 2. Executable Steps & Request Payloads

### Step 1: Create retail walk-in bill
- **Callable:** `billsCreate`
- **Request Payload:**
```json
{
  "salesMode": "retail",
  "paymentMethod": "cash",
  "paidAmount": 25000,
  "items": [
    {
      "productId": "prod_1",
      "quantity": 2,
      "unitPrice": 12500
    }
  ]
}
```

### Step 2: Finalize bill and commit stock/account ledger
- **Callable:** `billsFinalize`
- **Request Payload:**
```json
{
  "billId": "bill_001"
}
```

### Step 3: Verify financial account running balance updated
- **Callable:** `accountEntriesList`
- **Request Payload:**
```json
{
  "sourceDocumentType": "bill",
  "sourceDocumentId": "bill_001"
}
```


## 3. Invariant Assertions & Expected State
- **INV-1:** Must hold before and after each transaction in this flow.
- **INV-2:** Must hold before and after each transaction in this flow.
- **INV-3:** Must hold before and after each transaction in this flow.
- **INV-4:** Must hold before and after each transaction in this flow.
- Balance updates must be atomic and synchronized across running balance fields.
