## Cheap wins (measured; not applied)

- **Duplicate reads in one request**: 45 callables read a document twice with no write in between: `requestsMeta` (6 per call), `ledgerVerify` (3.1 per call), `employeesList` (3 per call), `requestsGet` (2.44 per call), `billsGet` (2 per call), `branchesDeactivate` (2 per call), `plansCatalogList` (2 per call), `reconcileBranchCounts` (2 per call). Each is one read per call that a local variable would save.
- **List reads per page**: `permissionCatalogList` 116, `platformUsersList` 43, `employeesList` 30, `auditLogsList` 26, `organizationsList` 21 reads for a typical page; a smaller default page or a field selection lowers egress, not reads.
- **`count()` on every page**: removed from `auditLogsList` (now `includeTotal: true` only); the per-entity history no longer reads every event of the entity before taking 50.
- **Gate membership cache (owner decision)**: the gate reads 5.11 documents per gated call on average. A per-instance cache of the membership read for a few seconds would save up to one read per call per user; the price is that a revoked membership keeps working until the cache expires. Not applied.
