## Cheap wins (measured; not applied)

- **Duplicate reads in one request**: 38 callables read a document twice with no write in between: `employeesList` (3 per call), `billsGet` (2 per call), `branchesDeactivate` (2 per call), `reconcileBranchCounts` (2 per call), `usageGetBranches` (2 per call), `usageRecordClientMetric` (1.67 per call), `branchesUpdate` (1.6 per call), `auditLogsList` (1.5 per call). Each is one read per call that a local variable would save.
- **List reads per page**: `permissionCatalogList` 115, `platformUsersList` 42, `auditLogsList` 27, `employeesList` 15, `organizationsList` 14 reads for a typical page; a smaller default page or a field selection lowers egress, not reads.
- **`count()` on every page**: removed from `auditLogsList` (now `includeTotal: true` only); the per-entity history no longer reads every event of the entity before taking 50.
- **Gate membership cache (owner decision)**: the gate reads 4.69 documents per gated call on average. A per-instance cache of the membership read for a few seconds would save up to one read per call per user; the price is that a revoked membership keeps working until the cache expires. Not applied.
